# Lernunterstützung

Eine einfache, kinderfreundliche Lern-Website für GitHub Pages.

## Enthalten
- Zahlen 0–9 erkennen
- Farben erkennen
- Formen erkennen
- Bilder/Zuordnung
- Tiere erkennen
- Zahlen nachspuren
- zufällige Aufgaben
- große Schaltflächen
- freundliche Rückmeldungen ohne Zeitdruck
- Einstellungen für Töne und Animationen
- responsive Darstellung für Tablet, PC und Smartphone

## Auf GitHub Pages veröffentlichen
1. Dieses Projekt als Repository `Lernunterstützung` anlegen.
2. Alle Dateien hochladen.
3. In GitHub: **Settings → Pages**.
4. Als Quelle **Deploy from a branch** auswählen.
5. Branch `main` und Ordner `/ (root)` auswählen.
6. Speichern.

Danach stellt GitHub Pages die `index.html` als Website bereit.

## Hinweis
Die Illustrationen sind als einfache Emoji-/CSS-Grafiken umgesetzt, damit das Projekt ohne externe Bildrechte oder externe Server auskommt. Die Bildhälften-Aufgabe ist in dieser ersten Version bewusst sehr einfach als Bild-zu-Bild-Zuordnung gehalten.
